# Инженерная практика оценивания моделей — том 6

Учебный оценочный стенд к монографии П. А. Пылова, Р. В. Майтака и А. В. Протодьяконова.

Репозиторий: https://github.com/MaytakRoman/model-evaluation-engineering-vol6

## Быстрый запуск

Требуется Python 3.10 или новее. Сторонние зависимости, API-ключи и сеть не нужны.
Распакуйте файлы в одну папку, откройте терминал в ней и выполните:

```bash
python3 run_all.py
python3 verify_results.py
python3 -m unittest discover -s tests
python3 verify_checksums.py
```

В Windows вместо `python3` обычно используется `py -3` или `python`.
`run_macos.command` и `run_windows.bat` запускают те же операции.
Для macOS при необходимости: `chmod +x run_macos.command`.

## Данные и границы вывода

Все данные искусственные. 600 строк в `data/acceptance_cases.jsonl` — контрольная
конструкция с 552 приемлемыми исходами, 0 критических событий и 582 своевременными
завершениями. Это не результаты коммерческой модели, реальных людей или заказчика.
Поле `data_kind` прямо обозначает `synthetic_fixture`.

`run_all.py` читает поставляемые JSONL и конфигурацию, а не подменяет их встроенным
примером. Результаты записываются в `lab_results`; исходный контроль находится в
`control_results`. Не редактируйте контроль ради успешной сверки изменённых данных.

Простая точная биномиальная процедура требует независимых испытаний и своего
дизайна. Уникальный номер строки не доказывает независимость. Для вопросов из общих
документов сохраняйте группы и применяйте соответствующий анализ. Модуль
`statistics_eval.py` демонстрирует групповой парный бутстреп; учебные группы в нём
слишком малы для серьёзных эмпирических утверждений.

Автоматический судья здесь представлен контрактом и валидатором, а не внешней LLM.
Его предметное качество необходимо калибровать независимо. Агент действует только
в локальной среде в памяти. Модуль безопасности не выполняет внешних атак.
Статистический флаг прохождения не является автоматическим разрешением внедрения.

## Целостность и повторное использование

`SHA256SUMS.txt` описывает неизменяемые файлы этой поставки. Сам файл контрольных
сумм и изменяемая папка `lab_results` в перечень не входят. После изменения исходника,
данных или конфигурации прежняя проверка должна сообщить расхождение.
Сохраняйте фактический коммит или релиз после публикации для научной ссылки.

В корень нового репозитория загрузите содержимое архива с сохранением папок.
Название: **model-evaluation-engineering-vol6**; владелец: **MaytakRoman**.
Архив можно также приложить к фактически созданному релизу.

При замене учебных данных фактическими сохраняйте происхождение, независимые
группы, все статусы и правила анализа. Не размещайте закрытые журналы в открытом
репозитории без установленного основания. Открытый комплект может содержать схему,
искусственные примеры и воспроизводимый анализ без раскрытия первичных документов.
